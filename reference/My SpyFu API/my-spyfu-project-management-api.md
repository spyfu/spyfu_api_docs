The My SpyFu Project management API offers a very rich set of actions -- anything you can do in My SpyFu you can do programmatically with the API.

It's a free to use, and is part of our version 1 API.  The documentation is housed on [https://spyfu.com/api/v1/project-manager](https://spyfu.com/api/v1/project-manager)
